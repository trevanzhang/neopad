# NeoPad 0.7.3

2026-10-12 local Windows test distribution. No tag or GitHub Release has been published.

This calculator milestone belongs to the 0.7.x local test series. The current
installer is [0.7.4](v0.7.4.md), which also includes loans and bond repos.

- Open the offline financial calculator from Tools or Shift+F6.
- Left navigation, grouped parameters, a top target result and fixed actions.
- Bond yield is the default tool. Regular coupon dates are automatic.
- Bond price/yield, durations, convexity, yield DV01; negative yields and 1/2/3/4 payments per year.
- Interest at maturity and discount bonds use explicit simple annual investment yields.
- Interest, rates and PV/FV/PMT tools, complete Markdown records, safe insertion and one-step undo.

See [supported financial conventions](../financial-tools.md). Domestic Wind / ChinaBond conventions, floating/stepped coupons and embedded options await separate verification.

This milestone is documented as 0.7.3; the current source and installer are
0.7.4. Public distribution remains subject to the existing signature and release checks.
