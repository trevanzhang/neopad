# NeoPad 0.7.6

2026-11-26 local Windows test distribution. No tag or GitHub Release has been published.

This compatible patch optimizes workspace metadata reconciliation, batch note
reads, sidebar refreshes, and background polling while preserving existing note
storage, financial tools, and Agent interfaces.

- Add a `mtime` + file-size fast path with a 2-second racy-clean window to
  `reconcile_note_metadata`, skipping full-file reads and SHA-256 hashing for
  unchanged notes outside the racy window while preserving safe detection of
  rapid same-length external writes.
- Backfill cached file stats for legacy `tabs.json` entries without bumping
  `updated_at`, and lazily scan `projects/` during location recovery only when
  a tracked project file is missing.
- Add `read_note_for_tab` and reuse loaded `NoteTab` records across full-text
  search, AI excerpt search, reminder scans, and ZIP exports to eliminate
  repeated `tabs.json` parsing.
- Consolidate F4 library refreshes into a single `get_library_snapshot_command`
  IPC call under one workspace lock and reconciliation pass.
- Remove redundant full-workspace reconciliation before checked autosaves
  (`write_note_command`), preserving direct external-modification detection.
- Pause the 2-second workspace polling loop while hidden to tray and sync
  immediately when the window becomes visible or regains focus; skip redundant
  `listReminders` scans once notification permission is granted.

Includes the financial calculator and cash-flow tools from [0.7.5](v0.7.5.md).

Source versions in Cargo, JavaScript and Tauri are synchronized at 0.7.6.
Validation: 138 Rust tests and 166 frontend tests passed, including new unit
coverage for the stat-cache fast path, racy-window rehashing, legacy stat
backfill, library snapshots, direct tab reads, and reminder polling.
Formatting, Clippy (`-D warnings`), version sync, production frontend build,
and Windows MSI packaging passed; local MSI upgrade from 0.7.5 was verified on
Windows. Other platforms were not built on this host.
Public distribution remains subject to the existing release checks.
