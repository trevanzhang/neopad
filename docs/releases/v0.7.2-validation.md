## Outstanding Release Gates

Windows Authenticode status is **NotSigned** for the MSI, desktop executable,
and CLI. These artifacts must not be published as unsigned public installers.
Signing changes bytes, so any signed replacement needs a new checksum manifest.

The packaged clean-install/upgrade and manual smoke checklist have not been run.
The user's installed app and live workspace were not used for these checks.
The source base passed Windows desktop E2E and macOS/Linux compilation in GitHub
CI; those runs precede the uncommitted version/documentation/checksum changes.
Desktop E2E was not rerun for this preparation.

macOS DMG and Linux DEB/AppImage have not been built for 0.7.2. GitHub CI on the
final release commit, the three-platform draft build, platform smoke checks,
signature/notarization checks, and owner-authorized publication remain pending.
