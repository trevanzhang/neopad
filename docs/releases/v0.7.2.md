# NeoPad 0.7.2

Status: release preparation. This document does not announce a published
GitHub Release. Build and verification results must be recorded before
publication; see [Release preparation](../release.md).
The [local Windows validation record](v0.7.2-validation.md) records the current
MSI hash, passed checks, and outstanding release gates.

## Highlights

- Open and edit the workspace Agent guide from Settings > Agent tools.
  A default `AGENTS.md` is created only when absent; existing guides, including
  empty files, survive startup and CLI repair.
- Show in Explorer selects the intended note in the matching Windows folder,
  including Unicode and punctuated paths. Selection failures are reported
  without marking saved content as unsaved.
- Resize the compact file browser with its saved divider width; Projects
  appears before Archive. Keyboard resizing and double-click reset are supported.
- Update Markdown, formula, diagram, and TLS dependencies, and restore strict
  lint checks. Stabilize Windows desktop E2E startup for WebView2 150+.

## Upgrade

From 0.7.1, this is a compatible update. Back up the complete NeoPad workspace
before installation, quit the old desktop app, and launch the new version once
to deploy its matching native CLI. Confirm the version in Help > About NeoPad
and CLI readiness in Settings > Agent tools.

From 0.6.x or earlier, the intervening 0.7 changes also apply:

- The MCP server, endpoint, and token configuration have been removed. Update
  Agent configurations to use the [native CLI](../cli.md#migrate-from-mcp).
- The reusable prompt library has become ordinary project Markdown notes.
  Migration preserves original bodies, categories, and trash records, avoids
  overwriting project files, and resumes interrupted moves. See
  [Projects and migration](../projects.md).
- Project notes share search, reminders, revision checks, recovery, and export.
  Capture notes remain flat under `notes/`; project notes use `projects/`.

## Packages and Verification

Expected packages: Windows x64 MSI, macOS ARM64 DMG, and Linux x64 DEB/AppImage,
with a SHA-256 manifest for each platform. Verify hashes after downloading.
The draft remains unpublished pending package smoke checks and platform
signature/notarization verification. The current build workflow does not
configure these signatures.

Window opacity and autostart remain Windows-only. macOS and Linux are checked
for compilation; their packaged runtime behavior requires platform smoke tests.
