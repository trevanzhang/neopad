# NeoPad 0.7.4

2026-10-12 local Windows test distribution. No tag or GitHub Release has been published.

At the user's direction, this compatible addition uses a patch increment in
the 0.7.x local test series, preserving existing note storage and Agent interfaces.

- Add personal loans: equal payments and equal principal, solve payment / principal / nominal annual rate, and inspect every repayment.
- Add bond repos: distinguish financing and lending, show gross interest, fees, net income / cost and signed cash flows.
- Select Shanghai / Shenzhen repo products or custom terms, enter actual funding days or actual settlement dates, and choose fee timing.
- Keep grouped forms, fixed actions, separate drafts, complete Markdown records and protected note insertion. No repeated page title.

Includes the calculator and bond tools from [0.7.3](v0.7.3.md).

See [financial conventions and limitations](../financial-tools.md). Loan schedules use unrounded amounts; they do not reproduce contract-specific cent rounding or floating rates. Repo calculations require actual funding days / settlement dates; there is no automatic exchange holiday calendar or broker fee lookup.

Versions in Cargo, JavaScript and Tauri are synchronized at 0.7.4. This is a local test installer; public distribution remains subject to the existing release checks.

Functional validation before the version correction: 125 Rust tests, 157
frontend tests and 25 desktop tests passed; light / dark themes and small
windows were checked from desktop screenshots. After correcting the version,
version sync, release-tag consistency, production frontend build and Windows
MSI packaging passed again. The application, CLI and MSI report 0.7.4.
