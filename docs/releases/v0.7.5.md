# NeoPad 0.7.5

2026-10-12 local Windows test distribution. No tag or GitHub Release has been published.

At the user's direction, this compatible addition uses a patch increment in
the 0.7.x local test series, preserving existing note storage and Agent interfaces.

- Add bond holding-period returns: clean / full quotes, accrued interest,
  actual coupons, transaction fees and financing costs. Separate net profit,
  price gain, holding return and simple annualization.
- Add effective annual return / cost (XIRR) from actual dated receipts and
  payments. Include borrowing fees, staged investments or repayments; sort
  and net same-day flows. The initial scope supports one sign change and
  rejects ambiguous cash-flow patterns.
- Move the financial calculator shortcut to `Shift+F1` for one-handed access.
  Plain `F1` still opens help; plain `F6` still opens reminders.
- Preserve compact grouped forms, session drafts, complete Markdown records
  and protected note insertion. Include original and normalized XIRR flows
  in records; no repeated page-title header.

Includes the loan and repo tools from [0.7.4](v0.7.4.md).
See [financial conventions and limitations](../financial-tools.md).
Holding-return annualization is simple and does not reinvest coupons. XIRR
uses a fixed 365-day year and actual cash-flow amounts; omitted fees or taxes
are not inferred, and the result is not a regulatory APR.

Source versions in Cargo, JavaScript and Tauri are synchronized at 0.7.5.
Validation: 133 Rust tests, 164 frontend tests and 27 desktop tests passed,
including native finance commands, Shift+F1, dated row editing, copy / protected
insertion, one-step undo, light / dark themes and 720 / 420-pixel layouts.
Formatting, version sync, release-tag consistency, production frontend build
and Windows MSI packaging passed. App, CLI and MSI report 0.7.5; SHA-256
manifests are generated locally. Other platforms were not built on this host.
Public distribution remains subject to the existing release checks.
