# 金融计算器

从「工具 → 金融计算器」或 `Shift+F1` 打开，`Esc` 关闭。`F1` 仍打开帮助，`F6` 仍为提醒列表。原 `Shift+F6` 不再打开金融计算器。
所有计算在 `neopad-core` 离线完成，没有行情请求。输入在本次启动内保留；重启恢复示例，不写入配置。预填数值不是行情。

默认打开「债券收益 → 到期收益率」。左侧选择工具，右侧依次为计算类型、债券类型、参数设置；目标结果在上方，计算、恢复示例、复制和插入按钮固定在底部。规则付息日自动生成，计息基准、偿还价值和持仓在高级设置中。

## 当前工具

| 工具 | 输入与口径 | 结果 |
| --- | --- | --- |
| 单利 | 本金、年利率、年数，或起止日期 | 利息、终值、年数、实际天数 |
| 复利 | 名义年利率、每年复利次数、完整总期数 | 终值、利息、每期利率 |
| 利率换算 | 名义年利率 / 有效年利率 / 支付周期利率，C/Y 与 P/Y 分开 | 三种对应利率 |
| 现值 / 年金 | 求 PV、FV 或 PMT；名义年利率、C/Y、P/Y、总期数、期初 / 期末、现金流方向 | 目标值、有效每期利率 |
| 通用债券 | 规则固定票息、到期还本、每年 1 / 2 / 3 / 4 次付息；价格与 YTM 互算 | 净价、全价、应计利息、YTM、麦考利与修正久期、凸性、收益率 DV01、持仓金额 |
| 到期一次付息 / 贴现债券 | 单次偿付；前者输入发行日和票息，后者无票息；单利年化投资收益率 | 净价、全价、应计、YTM、久期、凸性、DV01、现金流 |
| 个人贷款 | 等额本息 / 等额本金；求还款额、贷款总额或名义年利率 | 首末期还款额、递减额、总利息、总还款额、全期明细 |
| 债券持有期收益 | 整笔持仓的买卖日期、面值、净价 / 全价、应计、实收票息、交易费用与融资成本 | 净收益、价格损益、持有期收益率、单利年化 |
| 真实年化收益／成本（XIRR） | 2–200 笔实际日期、收支方向和实际金额；包含费用 | 有效年率、收支总额、净现金流、按日合并的现金流 |
| 债券回购 | 正回购 / 逆回购；沪深品种或自定义；实际占款天数、年利率、一次性费用 | 利息、手续费、融资成本 / 净收益、资金流、成交金额基准的折算年率 |

百分比输入 `3` 表示 3%。货币使用基本单位；债券价格按百元面值，持仓面值单独缩放金额。数字输入不识别千分位、单位文字或表达式。总期数为 1–100000 的整数；复利和支付频率为每年 1–366 次。

资金日期使用 `[起日, 止日)`，支持 Act/365F、Act/360、按日历年拆分的 Act/Act ISDA。复利不处理零头期；TVM 收入为正、支出为负，零利率使用连续极限。负资金利率必须满足数学定义域。

## 通用债券口径

- 结算日必须早于到期日。依据到期日向前生成规则日程，并在结果中展示上次与下次付息日及剩余支付次数；普通界面无需手填付息日，核心 API 仍可校验显式提供的日程；月底规则可显式启用。结算日当天票息视为已支付。
- 支持按付息周期的 Actual/Actual 和 US (NASD) 30/360；资金的 Act/Act ISDA 与债券的付息周期 Actual/Actual 分开。
- 多期价格使用 `Σ CF/(1+y/f)^(DSC/E+k)`；仅余一次付息时使用简单折现 `(C/f+R)/(1+y×DSC/(f×E))`。全价减应计利息为净价。
- 久期、凸性和 DV01 从同一定价分支派生。凸性为 `P″/Pfull`，收益率使用小数年利率；单位年²。DV01 为 `−dP/dy × 0.0001`，是年化到期收益率微小变化的价格敏感度，不能当作曲线平移或关键期限风险。持仓 DV01 = 每百元 DV01 × 面值 / 100。
- 支持负 YTM：多期规则付息需 `1+y/f>0`，最后一期与到期单次偿付需 `1+y×t>0`。规则付息票息与偿还价值必须为正。每年三付为通用模型扩展，不能称为 Excel PRICE 的 frequency 兼容项。
- 到期一次付息：`repayment=R+100×coupon×yearFraction(issue,maturity)`，`AI=100×coupon×yearFraction(issue,settlement)`。贴现债券：`repayment=R`，`AI=0`。全价均为 `repayment/(1+y×t)`，`t=yearFraction(settlement,maturity)`；报价 YTM 是单利年化投资收益率，不是银行贴现率或复利有效年收益率。提供 Act/365F、Act/360、Act/Act ISDA、NASD 30/360；NASD 常规日期样例可对照 PRICEMAT / YIELDMAT，ISDA 不等同于 Excel basis 1。
- 尚不支持不规则首末期、浮息、差别利率、含权、违约或摊还现金流；不自动推断存单等券种规则。没有税费、节假日或营业日调整。
- 非线性求根必须回代至每百元价格残差不超过 `1e-10`，否则返回错误；不以零值代替失败结果。

这些公式用于通用测算和适用范围内的 Excel 对照。**国内 Wind / 中债估值模式尚未开放**。公开估值表的输出字段不足以确认计算口径；历史标准的废止也不能用于推断当前软件实现。接入国内模式仍需要有版本的算法说明、券种与计息规则，以及可独立复核的结算日 / 付息日 / 净价 / 全价 / 应计 / YTM 样例。

参考：[Microsoft PRICEMAT](https://support.microsoft.com/en-us/excel/functions/pricemat-function)、[YIELDMAT](https://support.microsoft.com/en-us/excel/functions/yieldmat-function)、[Microsoft PRICE](https://support.microsoft.com/en-us/excel/functions/price-function)、[YIELD](https://support.microsoft.com/en-us/excel/functions/yield-function)、[MDURATION](https://support.microsoft.com/en-us/excel/functions/mduration-function)、[FV](https://support.microsoft.com/en-us/excel/functions/fv-function)、[Strata day counts](https://strata.opengamma.io/day_counts/)。国内依据和失效历史文号见 [实施计划](financial-tools-plan.md)；公开字段可见 [中债估值](https://indices.chinabond.com.cn/cbweb-mn/val/val_query_list?locale=zh_CN)。

## 个人贷款

支持固定名义年利率、期末偿还的等额本息与等额本金。贷款期限以月填写，范围 1–1200 个月；偿还频率支持每月、每季、每半年或每年，期限须为完整偿还周期。年利率输入 `3.5` 表示 3.5%，支持 0%–1000%。示例参数仅用于演示。

设本金为 `P`，名义年利率为 `r`，每年偿还次数为 `f`，期数 `n=months×f/12`，期利率 `i=r/f`。等额本息每期还款为 `P×i/[1−(1+i)^−n]`，零利率为 `P/n`。等额本金第 `k` 期还款为 `P/n+[P−(k−1)×P/n]×i`。

可反算本金和年利率。等额本金的反算明确以**首期还款额**为输入；低于零利率还款额时，不存在支持范围内的非负利率，返回错误。年利率通过同一还款公式回代验证。

明细包含每期还款、本金、利息和剩余本金，逐批显示 50 期；复制或插入完整记录包含所有期数。计算使用未舍入数值，界面显示到分，未模拟银行逐期分位舍入、手续费、提前还款、浮动利率或合同中的特别规则。参考：[Microsoft PMT](https://support.microsoft.com/en-us/excel/functions/pmt-function)、[Microsoft RATE](https://support.microsoft.com/en-us/excel/functions/rate-function)。

## 债券回购

正回购为融入资金：起始收取本金，到期支付本金和利息，融资成本为利息加手续费。逆回购为融出资金：起始支付本金，到期收回本金和利息，净收益为利息减手续费，可能为负。界面显示收入为正、支出为负的两端资金流，费用可指定起始或到期扣取。

沪市品种为 `204001/002/003/004/007/014/028/091/182`；深市为 `131810/811/800/809/801/802/803/805/806`，对应名义期限 1、2、3、4、7、14、28、91、182 天。品种代码只作为期限上下文，**不自动替代实际占款天数**，也不计算保证金或标准券折算。代码参考：[深交所 2026 年 6 月月报](https://docs.static.szse.cn/www/market/periodical/month/W020260706503110212908.html)。

可手填实际占款天数（1–36600 天），或按 `[首次实际交收日, 到期实际交收日)` 计算日历天数。填写的是交收日，不是成交日。未接入交易所节假日及资金可用 / 可取日历，不自动计算交收日。沪深标准品种以 365 天年基准计息，自定义回购可选 360 或 365。交易所实际占款天数规则参考：[上交所债券回购交易实施细则修订说明](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20170519_4313753.shtml)。

`利息 = 成交金额 × 年利率 × 实际占款天数 / 年基准`；`手续费 = 成交金额 × 一次性手续费率`。手续费输入 `.001` 表示 0.001%，按成交金额计收一次，不使用名义期限乘费、不预设券商佣金或最低收费。默认费率为零，需按实际合同填写。

净收益 / 成本的折算年率以成交金额作分母，等于 `净收益或成本 / 成交金额 × 年基准 / 实际占款天数`，不等同于扣费后的现金流 IRR 或融资 APR。实际手续费、费率、交收天数需与成交确认书核对。

## 债券持有期收益

适用于同一笔持仓完整买入和卖出。买卖日期按实际结算日期填写，卖出日期必须晚于买入日期。面值用于将百元报价换算为实际金额；选择净价时另外填写每百元应计利息，选择全价时不使用应计字段。

`全价 = 净价 + 应计`；`买卖金额 = 面值 / 100 × 全价`。实收票息、买卖手续费和融资成本均填**这笔持仓的实际总金额**，不会再乘面值。票息需自行按实际到账填写；税费可纳入对应费用，不自动计算税率。

`净收益 = 卖出金额 − 买入金额 + 实收票息 − 买入费用 − 卖出费用 − 融资成本`。
`持有期收益率 = 净收益 / (买入金额 + 买入费用)`。
`单利年化 = 持有期收益率 × 365 / 实际持有天数`，天数按 `[买入日, 卖出日)` 计算。

可显示负收益。分母是买入投入，不是杠杆交易的自有资金，融资成本仅作费用扣除。不自动生成票息、不模拟票息再投资、不处理分批买卖或本金摊还。单利年化不考虑中间票息到账时间；需考虑到账日期时使用下面的 XIRR。参考：[CFA 持有期收益](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/portfolio-risk-return-part-1)。

## 真实年化收益／成本（XIRR）

逐笔录入实际收付款日期、方向及非负金额。从自己的角度：投资买入为支出，票息及卖出款为收入；借款到账为收入，手续费及还款为支出。分期还款、前扣费用和中间票息都可以单独录入，不使用票面或广告利率代替实际现金流。数字格式与其他工具相同，不含千分位或单位文字。

核心按日期排序并合并同日净额，零净额不参与求根。合并后至少两个不同日期且须同时有正负现金流；首版支持**恰好一次变号**，包括连续投入后连续回款，或借款到账后连续还款。多次变号可能对应多个或不存在的利率，明确拒绝，未擅自选取某个根。错误定位到具体输入行时显示行号。

求解 `Σ CF_i / (1+r)^((日期_i−首个有效日期)/365) = 0`；年固定为 365 天，闰年也不改成 366。结果是小数利率的百分比展示，可为负；范围 −99.9999% 至 100000000%。通过对数域求根，回代相对残差 `|NPV| / 总绝对现值 ≤ 1e-10`，超范围或不收敛返回错误。

收支总额基于原始输入，现金流明细展示排序合并后的净额；完整记录保留两者。首个有效日期和末个有效日期的间隔不含完全抵消的首尾日期。可手动添加或删除现金流，最多 200 笔，不自动读取贷款明细或导入文件。

“真实年化”表示按实际现金流计算的有效年率；尚未录入的税费不包含在结果中，不表示法定贷款 APR 或合同结算口径。参考：[Microsoft XIRR](https://support.microsoft.com/zh-cn/excel/functions/xirr-function)、[XNPV](https://support.microsoft.com/en-us/excel/functions/xnpv-function)。官方样例按发布精度核验，同时独立回代折现现金流。

## 记录与笔记

国内模式核验记录（2026-10-12）：[Wind Client API 官方介绍](https://www.wind.com.cn/portal/zh/ClientApi/index.html)说明其债券计算器引擎可执行净价、全价、收益率互算并与终端一致，但公开页面没有给出可据此实现的完整公式及边界规则。尚未获得有版本的口径规格和独立基准，因此继续保留上线门槛。

「复制结果」使用显示精度；「复制完整记录」包含实际参与计算的输入、口径、未按显示位数舍入的数值、公式、引擎版本、债券现金流、XIRR 原始与按日合并现金流及全期贷款明细。显示金额两位小数，其余一般六位，计算不使用显示值。

参数或工具类别变化立即清除旧结果，复制和插入需要重新计算，晚到的计算响应不会覆盖新参数的结果。工具间输入分别保留，「恢复示例」只恢复当前类别的示例。

打开面板时捕获笔记、光标和文档版本；插入只增加文本，不替换选区。目标笔记、内容或修订变化时拒绝插入，改用复制记录。插入进入现有编辑 / 自动保存流程，一次撤销可完整移除记录。纯预览模式可计算和复制，不能插入；编辑与分屏模式可插入。面板打开时阻止底层笔记快捷操作，Tab 在面板内移动，F9 切换明暗主题。
