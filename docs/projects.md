# 项目笔记

适用于 NeoPad 0.7.1 及以后版本。

NeoPad 的文件浏览器分为快速捕获、项目、存档和回收站。项目用于保存与某件
事情有关的普通笔记，不引入任务看板、知识库或独立 AI 会话。

```text
~/.neopad/
  notes/                       平铺的快速捕获笔记（含 Inbox、Clipboard）
  projects/<项目>/<分类>/*.md   活动项目笔记
  archive/projects/<项目>/     整体归档的项目，保留目录结构
  trash/                       可恢复的笔记文件
  meta/tabs.json               笔记 ID、目录位置、回收位置等元数据
```

按 F4 打开文件浏览器。在项目根部新建目录；双击目录或使用右键菜单新建笔记。
文件区域按“笔记、项目、存档、回收站”排列。拖动右侧分隔条可以调整宽度，
调整结果在本机自动记住；双击分隔条恢复默认宽度。分隔条获得焦点后，左右
方向键也可调整宽度。窗口缩小时会自动限制文件区域宽度，给编辑区保留空间。
项目笔记使用普通标签页、自动保存、搜索、提醒和导出。可以将快速捕获、项目
或存档笔记拖入项目目录，将项目笔记拖回快速捕获，也可以拖动整个项目目录。
项目根部的加号会依次询问项目目录和笔记标题。

也可以右键笔记标签页，选择“移动到项目”，再点击目标项目或子目录，无需打开
文件浏览器。菜单每次打开都会刷新项目列表，当前所在目录会打勾并禁用。
移动前保存编辑内容，移动后保留笔记 ID 和当前标签页；已归档的笔记也可以
直接移回项目。默认页、剪贴板页和外部文件不支持此操作。没有项目时按 F4 新建。

右键项目目录可以新建子目录、重命名、整体归档或删除。整体归档移动到
`archive/projects/<原目录>/`；恢复单篇笔记会重建原来的项目目录。删除项目
仅将其中的 Markdown 笔记移到回收站，然后清理空目录。目标已存在时拒绝覆盖。
含符号链接、目录链接或非 Markdown 文件的目录不会被整体移动或删除。

项目笔记的 ID 在移动和目录重命名后保持不变。Agent 使用同一套
[CLI 笔记接口](cli.md#项目笔记071-起)，整页更新仍需 `expectedUpdatedAt`。
不同项目可以有同名 Markdown 文件，回收站会分别记录其准确位置；恢复时不会
覆盖同名文件。全部笔记 ZIP 导出保留 `notes/`、`projects/` 和 `archive/` 的层级。

## 旧提示词迁移

首次打开旧工作区时，应用或 CLI 自动将 `prompts/**/*.md` 转为
`projects/原提示词/**/*.md` 中的普通笔记。正文不改写，嵌套分类和空文件保留。
旧 `trash/prompts/` 中的文件也转为普通回收站记录，恢复后进入原提示词项目。
没有旧元数据的回收文件会归入 `原提示词/Recovered/`。

迁移先记录笔记元数据，再移动文件。中途关闭后可以继续，不会重复导入。
若目标已有同名文件，迁移会选择 `原提示词-1/` 等新目录，保留双方内容。
旧 `meta/prompts.json` 和空的旧目录保留为迁移历史；新工作区不再创建它们。
提示词库管理、Ctrl+K 附加选择器和提示词专用标签页/API 已移除。

测试和首次升级前可备份整个工作区。旧版本不识别新项目元数据，降级应使用
升级前的完整备份；不要让新旧版本同时写同一个工作区。
